# Code and dataset for Experimental Economics project, M1 TSE

### Authors: Mira Choi, Carrie Liang, Mehak Rawal

### AI Use Statement

The majority of this code was generated by Claude with experimenter guidance and prompts for fine-tuning. Claude was also used to generate possible project designs, but the experimenters refined and reiterated to make the design more faithful to our original objectives and real-life constraints. Responses remain anonymized by randomly assigning participant IDs.

The original project idea was human-conceived, inspired by the CROUS queueing situation in French universities. We were inspired to choose this topic seeing extremely long queues for meals at CROUS, but classmates had various different reasons for choosing to wait in line, or eating their lunch elsewhere. We isolated three of these factors to test in the experiment: boredom while waiting (vs. having a distraction, such as devices or in reality, socialization), cost of meal, and meal budget.
